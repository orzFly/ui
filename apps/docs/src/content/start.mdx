## Install

<Install pkg="@orz/ui" />

`radix-ui`, `sonner`, `lucide-react` and React are peer dependencies, so they are your app's own
copies. Radix's focus and dismiss stacks and sonner's toast store are module state: with a second
copy beside yours, Escape would stop closing a menu opened over a dialog, and `toast()` would not
reach `<Toaster />`.

`@orz/themes` and `@orz/query` are `@orz/ui`'s own dependencies, installed beside it because your
app imports them too: the themes below come from `@orz/themes`, and a query box's schema from
`@orz/query`.

## CSS

```css
@import "tailwindcss";
@import "@orz/ui/styles.css";
```

`styles.css` brings the baseline tokens, the base layer, `tw-animate-css` and shadcn's Tailwind
variants, and registers the package's own files with Tailwind, so you add no `@source` line for it.

It loads no fonts. The default style's faces are a separate import, with their own install line
above:

```css
@import "@orz/ui/fonts.css";
```

`fonts.css` loads Noto Sans and Noto Sans Mono for Latin, Greek, Cyrillic and Vietnamese, and Noto
Sans for Devanagari too; Chinese, Japanese and Korean come from the system, or from a font your app
loads. Without it, the system's faces draw everything.

A surface that shares its document with someone else's UI imports `@orz/ui/theme.css` instead: the
tokens and variants, with nothing that styles the page around it.

## Theme

A theme store holds the user's pick, paints it, and follows the OS and other tabs. It takes the
themes it may show, so your bundle carries only those.

```tsx
import { builtinThemes } from "@orz/themes";
import { Toaster } from "@orz/ui/components/sonner";
import { createThemeStore, ThemeProvider } from "@orz/ui/theme";
import { createRoot } from "react-dom/client";

const themes = createThemeStore({
  storageKey: "app-theme",
  themes: builtinThemes,
});

createRoot(document.getElementById("root")!).render(
  <ThemeProvider store={themes}>
    <App />
    <Toaster />
  </ThemeProvider>,
);
```

`<ThemeMenu />` from `@orz/ui/components/theme-menu` is a ready-made picker; the one in this site's
top bar is it. To keep a reload in a dark theme from flashing white, put
`themePaintGuardScript({ storageKey: "app-theme" })` in an inline `<script>` in `<head>`, as every
page of this site does.
